# `@inkgraph/desktop` (Tauri v2 Shell)

Shell nativo multi-plataforma (Windows, Linux/Wayland, macOS e alvos móveis Tauri v2) apontando diretamente para `@inkgraph/ui`.

## Pré-requisitos
- Rust + Cargo (`rustup`)
- Dependências de sistema do Tauri v2 no SO alvo

## Comandos
```bash
pnpm --filter @inkgraph/desktop tauri:dev
pnpm --filter @inkgraph/desktop tauri:build
```
